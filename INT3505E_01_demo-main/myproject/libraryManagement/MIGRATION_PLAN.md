# Kế hoạch Nâng cấp API MiniPay từ v1 lên v2

**Ngày công bố:** 01/12/2023

## 1. Lý do nâng cấp
API v2 được ra mắt để hỗ trợ đa dạng phương thức thanh toán và cung cấp cấu trúc dữ liệu minh bạch hơn về chi phí, đáp ứng nhu cầu phát triển của các đối tác.

## 2. Lộ trình (Timeline)
- **01/12/2023:** Ra mắt API v2. API v1 được chuyển sang trạng thái "Deprecated".
- **01/01/2024 - 01/06/2024:** Giai đoạn chuyển đổi song song. API v1 vẫn hoạt động nhưng không có tính năng mới.
- **01/06/2024:** API v1 ngừng hoạt động (End-of-Life). Mọi request đến v1 sẽ nhận lỗi.
